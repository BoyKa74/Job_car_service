# Website Car Service Shop

Dự án website cho cửa hàng dịch vụ sửa chữa và bảo dưỡng xe hơi.

## Tính năng

- Trang chủ với thông tin giới thiệu về cửa hàng và dịch vụ
- Danh sách dịch vụ với bộ lọc
- Trang giới thiệu về cửa hàng
- Form liên hệ
- Trang quản trị đơn giản để quản lý dịch vụ

## Công nghệ sử dụng

- Frontend: React, TypeScript, Bootstrap 5
- Thư viện: React Router, Axios, FontAwesome

## Cài đặt và chạy dự án

### Yêu cầu

- Node.js (phiên bản 14.x trở lên)
- npm hoặc yarn

### Các bước cài đặt

1. Clone dự án về máy:
```bash
git clone <repository-url>
cd car-service-shop
```

2. Cài đặt các thư viện:
```bash
npm install
```

3. Chạy dự án ở môi trường phát triển:
```bash
npm start
```

Dự án sẽ chạy tại địa chỉ [http://localhost:3000](http://localhost:3000).

## Cấu trúc thư mục

- `src/components`: Chứa các component tái sử dụng
- `src/pages`: Chứa các trang của ứng dụng
- `src/services`: Chứa các service để gọi API
- `src/assets`: Chứa hình ảnh và tài nguyên
- `src/styles`: Chứa các file CSS

## Phát triển thêm

Để phát triển thêm cho dự án, bạn có thể:

1. Tạo backend thực tế với Node.js và MySQL
2. Thêm chức năng đặt lịch hẹn trực tuyến
3. Thêm chức năng đánh giá và phản hồi từ khách hàng
4. Tích hợp thanh toán trực tuyến
5. Thêm chức năng theo dõi tiến độ sửa chữa
